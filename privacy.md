Privacy Policy for CyberByte
Effective Date: October 11, 2026

Thank you for using CyberByte ("the Bot"). This Privacy Policy explains how information is collected, used, and handled when you use the Bot and its associated services.

1. Information We Collect
CyberByte is designed with privacy in mind and collects the bare minimum amount of data required to provide threat intelligence and security alerts:

Guild (Server) Data: The Bot stores server IDs and configured channel names (specifically #cyberbyte-alerts) to deliver broadcast messages and security notifications.

Command Interactions: When you run slash commands like /setup, Discord processes the interaction. We do not permanently log or store the personal user IDs of individuals who run the setup command beyond standard operational execution.

2. How We Use Information
The information collected is used exclusively for:

Managing and verifying server alert channels via the /setup command.

Broadcasting global security advisories, scam warnings, and threat intelligence updates sent by the bot owner via the /alert command.

3. Data Storage and Security
The Bot does not collect, store, or process private direct messages (DMs), user messages, personal emails, or sensitive personal information.

All data necessary for operational functionality is kept secure and is never sold, traded, or shared with third parties.

4. Third-Party Services
CyberByte operates on the Discord platform and is hosted via secure infrastructure providers. Please refer to Discord's Privacy Policy for information regarding how Discord handles your data.

5. Data Deletion
Because CyberByte does not store persistent user databases, removing the Bot from your Discord server automatically revokes its access and stops any further interaction with your server. If you wish to purge a configured alert channel, server administrators can simply delete the #cyberbyte-alerts channel or remove the Bot.

6. Contact Information
If you have any questions, concerns, or requests regarding this Privacy Policy, you can reach out through the official CyberByte support server or contact the Bot Owner directly via Discord.
